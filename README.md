🍪 Easy Chocolate Chip Cookies Recipe Website
(Frontend Mentor Challenge)

This project was created as part of a Frontend Mentor challenge. The goal is to build a modern, responsive, and aesthetically pleasing recipe page using HTML and CSS. The page presents a classic chocolate chip cookie recipe with clear sections for preparation, ingredients, and nutrition.

🧱 Project Structure

📂 Project Folder

├── recipe.html        # Main HTML file

├── recipe.css         # CSS stylesheet

└── cookie.jpg        # Cookie image


🧁 Content

The page includes:

• Recipe Title and Description

• Preparation Time

• Ingredients

• Instructions

• Nutrition Facts

🎨 Design Features


• Responsive Design – Works well on all devices

• Google Fonts – Uses Roboto Condensed

• Soft Color Palette – Light pink tones

• Flexbox Layout – For flexible nutrition table layout


🚀 How to Run

1. Clone the repository:
   
   git clone https://github.com/simukiju/recipe.git
   
3. Navigate into the folder:
   
   cd recipe
   
5. Open recipe.html in your browser:
   
   open recipe.html
   
or just double-click the file.

🛠 Technologies Used

• HTML5

• CSS3

• Google Fonts
